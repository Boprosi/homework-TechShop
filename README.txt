Контрольные вопросы:
1. JavaScript нужен для добавления интерактивности и поведения веб-странице.
2. Внешний файл подключается тегом <script src="script.js"></script> перед закрывающим тегом body.
3. DOM — объектная модель документа, представляющая HTML-страницу в виде объектов.
4. querySelector() ищет первый элемент, подходящий под указанный CSS-селектор.
5. click — событие, которое происходит при нажатии на элемент.
6. addEventListener() назначает обработчик, который выполняется при наступлении события.
7. textContent читает или изменяет обычный текст внутри элемента.
8. Сообщение появляется после нажатия, потому что код изменения текста находится внутри обработчика события click.
9. #buy выбирает элемент по id="buy", а .product — элементы с class="product".
10. Если указать несуществующий id, querySelector() вернёт null. Попытка вызвать у него addEventListener() приведёт к ошибке.

Файлы проекта:
- index.html — структура страницы.
- style.css — оформление страницы.
- script.js — обработчики кнопок.
